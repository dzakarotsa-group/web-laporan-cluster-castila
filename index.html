Spreadsheet tim & lokasi proyek

Atur sumber data anggota Marketing, Ads, Konten, serta Admin per lokasi.

Marketing memakai satu baris per lead. Konten memakai kolom tanggal posting, properti, judul/topik, platform, views/reach, likes, comments, saves, shares, klik link/DM, dan catatan evaluasi.

Agar tab lain tidak ikut dibagikan, gunakan File → Bagikan → Publikasikan ke web di Google Sheets, pilih tab yang diperlukan dan format CSV, lalu tempel link publikasi di sini. Untuk Konten pilih tab Tracker Performa per Konten. Cara ini memublikasikan tab terpilih saja; jangan gunakan link berbagi biasa jika file memiliki tab privat.

Tambahkan tepat tiga spreadsheet divisi Admin, satu untuk setiap admin/lokasi proyek. Kolom Admin dibaca dari format progress/tracking unit seperti Tgl ITJ, Blok, Nama User, Marketing, Harga Jadi, Bank Tujuan, Status Berkas, Tgl Masuk Bank, WWC, Update/Hasil Bank, Target Akad, dan Progress Unit.
